# Write a short that earns its ending

Start with the supplied reference, audience, topic, and desired language. If a clip is available, inspect opening frames at one-second intervals, sample the entire middle, inspect the actual ending and measure the runtime. Identify the first action, the repeated object, when its meaning changes, who makes the decisive choice and the last image. Cite timestamps. Keep observed action separate from inferred motive. If only visual sampling was possible, describe words only where they were readable on screen.

If this is the paper-boat project, read `docs/reference-analysis.md`, `docs/production-guide.md` and `assets/story.json`. Otherwise use the framework below. Preserve the reference's timing logic while inventing a different situation, characters, wording and visual assets.

1. Write the ending image first. Give an ordinary object a second meaning through something the character does. Example premise: a father frames his daughter's paper boats to protect them. Example ending: the red boat's place on the shelf now holds a photograph of its first voyage.
2. Invent three materially different *first shots*. For each, provide the first spoken line, what a muted viewer sees and the question both raise. Choose the one whose question the planned last image answers. Omit a greeting or logo unless explicitly requested.
3. Build a causal beat sheet. A person wants something → a seemingly helpful habit interferes → a specific question exposes the cost → someone chooses → an attempt has a real setback → the protagonist acts → the original object returns changed. Give every beat a visible verb.
4. Write a conversational Hindi or Hinglish narration. Use one narrator, short clauses and concrete nouns. Give the characters at most a few brief quoted lines. Read dialogue aloud. Use clean Devanagari for Hindi TTS and keep directions, translations and Romanized captions in separate fields.
5. Start with a 45–65 second short unless the brief says otherwise. At 90–105 seconds, earn the extra time with another causal turn. If shortening, cut duplicate explanations before cutting the reaction that makes the payoff legible.
6. Score each dimension 0–2: the first image reads on mute, the opening creates a specific question, successive beats change the situation, a character earns the reveal, the end image resolves the opening. For a zero, name and rewrite the specific line or shot. The score is editorial judgment.
7. Deliver the hook options, chosen hook, clean narration, and a beat table with shot, action, emotion, line, camera and intended pause. If production is requested, write the script to the project and proceed to narration and animation. For a different story allocate fresh shot IDs and art. Preserve the finished demo in a separate folder.

After publication, look at stayed-versus-swiped, early drop-off and the retention curve at the question, setback and reveal if the creator supplies them. Mark unknown values as unknown. Never invent retention data.
