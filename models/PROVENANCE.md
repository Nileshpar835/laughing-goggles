# Voice assets

The two unmodified binary files are from the model-files-v1.0 release of thewh1teagle/kokoro-onnx. The quantized model is derived from hexgrad/Kokoro-82M; the release credits taylorchu/kokoro-onnx for conversion. Upstream states that the Kokoro model uses Apache License 2.0. A copy is included. The runtime wrapper is installed separately under its MIT license. The Hindi voice ID used here is hm_omega.

- Release and model asset URLs: https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0
- Model card and license: https://huggingface.co/hexgrad/Kokoro-82M
- Voice inventory: https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md
- Wrapper and usage: https://github.com/thewh1teagle/kokoro-onnx
- Claude Code skill locations: https://code.claude.com/docs/en/skills

The story, procedural artwork, score and sound effects were created for this project. The voice is synthesized. The analysis thumbnails are from the user-supplied video. The supplied reference film and its audio are excluded from the rendered episode.
